# Изменения

## Первый проход исправлений

- Один обработчик главной страницы организации и один модуль авторизации; обязательные разделы больше не пропускаются при ошибке импорта.
- Некорректные календарные даты возвращают ошибку формы, пустые названия задач не сохраняются.
- Перенос срока проверяет права администратора или исполнителя и на сервере.
- Завершение и отмена блокируют строку задачи на время транзакции. Два одновременных завершения создают один следующий повтор, отменённая задача не порождает повтор.
- Параметр `next` после входа разрешает только внутренние адреса.
- Исправлены повторное добавление столбцов в исторических миграциях и пустая миграция назначения задач. Новая ревизия явно разрешает задачи без назначения.
- Единая загрузка `.env` для приложения, CLI и Alembic; нет встроенных рабочих URL или секретов.
- CLI создаёт организацию и первого администратора без Dadata и готовых паролей.
- Исправлена передача имени руководителя при регистрации и обработка ошибки Dadata при создании организации администратором.
- Настраиваемые cookie, метка клона и отключение внешних интеграций; `/health` проверяет соединение с БД.
- Добавлены 8 регрессионных тестов на отдельной PostgreSQL-базе и workflow CI.

Исторические миграции исправлены для свежей установки. Уже применённые ревизии не выполняются повторно; изменение ограничения назначения доставляется новой ревизией `b20261027_task_target`. Перед обновлением существующей установки необходимы копия кода и резервная копия её базы.
